TASK 4: SQLITE DATABASE PERSISTENCE
================================================================================

FILE: pulse/database.py (33 KB)

SCHEMA (12 TABLES):
  1. trends: Strategic trends with Bayesian posteriors
  2. trend_category_exposure: Trend-to-category exposure matrix
  3. trend_vc_exposure: Trend-to-value-chain exposure matrix
  4. causal_edges: Causal DAG edges between forces (with lag, weight, mechanism)
  5. competitors: Competitive profiles (public intelligence only)
  6. config_snapshots: Configuration snapshots with all parameters
  7. simulation_runs: Bayesian MC results, causal decomposition, allocations
  8. backtest_results: Historical prediction accuracy calibration
  9. delphi_rounds: Expert elicitation scores, calibration, bias flags
  10. triggers: Early-warning trigger definitions and status
  11. ai_suggestions: AI scanning results pending human review
  12. audit_log: Change tracking with timestamp, user, reason

KEY FUNCTIONS:

  Trends:
    - save_trends(trends: List[Trend]) → None
    - load_trends() → List[Trend]
    - get_trend_by_id(trend_id: str) → Optional[Trend]

  Causal Edges:
    - save_causal_edges(edges: List[CausalEdge]) → None
    - load_causal_edges() → List[CausalEdge]

  Simulation Runs:
    - save_simulation_run(...) → int (run_id)
    - load_simulation_runs(limit=100, scenario=None) → List[Dict]

  Audit Log:
    - log_audit(action, entity_type, entity_id, ...) → None
    - get_audit_log(limit=100, entity_type=None) → List[Dict]

  Utilities:
    - init_db() → None (idempotent schema creation)
    - get_db_stats() → Dict[str, int] (record counts)
    - get_db_connection() → ContextManager (auto-commit)

SECURITY FEATURES:
  - NO financial data columns in schema (firewall by design)
  - All monetary values are RELATIVE (%, weights, shifts)
  - Audit log tracks all changes with user/timestamp/reason
  - Indexes on common queries (force, DAG edges, timestamps)

DATABASE PATH: data/pulse.db (created on first init_db() call)

STORAGE FORMAT:
  - Trends: Normalized to dataclass, exposures separated into junction tables
  - Posteriors: JSON serialized (alpha, beta tuples)
  - Results: JSON (flexible schema for MC samples, diagnostics)
  - Causal DAG: Edges normalized, weights in [0,1]

USAGE:
  from pulse.database import init_db, save_trends, load_trends
  
  init_db()  # Create schema once
  save_trends([trend1, trend2, ...])
  loaded = load_trends()
