# 02 — Findings Register

**Format:** `ID | Severity | Area (Pass) | Finding | Evidence | So-what | Recommendation | Effort`
Severity: P0 = invalidates results / could mislead leadership · P1 = must fix before leadership-facing use · P2 = robustness gap · P3 = hygiene. Strengths listed at the end with the same discipline.
Evidence grades: [hard] = verified in code/experiment · [⚡est] = consulting estimate, derivation stated · [⚠hyp] = hypothesis, needs validation.
